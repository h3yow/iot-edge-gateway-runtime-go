# iot-edge-gateway-runtime-go

进程内模拟的 IoT 边缘网关运行时（纯 Go 标准库）：消息接入与层级通配符订阅、
设备影子期望/上报双状态与版本合并、固件分批灰度发布与失败回滚，串成一条自洽链路。

## 快速开始

```bash
go run ./cmd/gateway          # 本机端到端演示
go test -race -count=1 ./...  # 全量测试（含竞态检测）
```

## 覆盖能力

- 主题层级订阅与 `+`/`#` 通配符匹配；拒绝原因区分未知设备 / 非法主题 / 通配符发布 /
  越权发布 / 越权订阅。
- `(deviceID, messageID)` 幂等入库：多设备并发上报、断线重连补投不重复、不丢失。
- desired / reported 分开版本化维护；离线期望暂存，重连补报后按 base 三方合并，
  冲突按“可控字段平台优先、只读字段设备优先”裁决并留痕；请求按 requestID 幂等。
- 固件 canary→批次灰度，支持多发布单并行：**全局同时安装设备总数有硬上限**，
  并发参数未填/0/负数自动兜底为安全值；设备已是目标版本按“已就绪”零安装处理；
  版本先后裁决拒绝低版本顶掉高版本、高版本自动接管旧发布单，
  被接管设备在重试/取消/回滚下都保持最新已发布版本；失败阈值/取消均收敛终态并回滚。
